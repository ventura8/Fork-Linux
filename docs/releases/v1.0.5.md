# Fork for Linux (unofficial) v1.0.5 — IDE icons, crisp text

Fork for Linux (unofficial) runs the **official, unmodified** [Fork](https://git-fork.com) git
client for Windows under Wine. Fork is made by **Dan Pristupov and Tanya Pristupova**; this
project is **not affiliated with, endorsed by or supported by** them. Fork is paid software:
the evaluation is free, please [buy a license](https://git-fork.com/buy) if you keep using it.
Report wrapper problems at https://github.com/ventura8/Fork-Linux/issues, not to Fork support.

## What's new

- **Open in shows each IDE's icon.** Fork displays the icon of the program it found for an editor,
  and the Wine stubs fork-linux puts there had none. Each stub now carries the icon of the Linux IDE
  it starts — the PNG named by `Icon=` in that IDE's desktop entry (system, snap and Flatpak entries
  are all found) — at 16 to 64 px, so it stays sharp at any scaling. No icon found: the entry is
  listed without one, as before.
- **Crisp, evenly spaced interface text.** Fork's interface font under Wine was Selawik, Microsoft's
  open-source stand-in for Segoe UI. Under Wine its hinting spaced letters unevenly ("Quick La unch",
  "Pu ll") and thin. FreeType's hinting modes, WPF's hardware rendering and its ClearType settings
  made no difference; the font did. The interface font is now **Noto Sans** 2.015 (SIL OFL 1.1),
  whose design comes from the same designer as Segoe UI: setup downloads its Regular, Bold,
  Semibold and Light faces (pinned, sha256-verified, 2.4 MB) and installs them under their own
  family name, **FL UI Sans**, so the desktop's own Noto Sans (often without a Semibold) cannot make
  Fork's headings and the current commit lose their weight. Noto Sans also covers Greek and
  Cyrillic, which Selawik did not.
- E2E: **I-OPEN-IN-IDES** checks the colour of every entry's icon on screen; **I-FONT-UI** checks
  that Fork draws with the new faces, semibold included.

## Upgrade

The next `fork` / `fork-linux run` downloads the four font faces once (2.4 MB) and refreshes the
Open in stubs. Fully quit Fork once so it starts with the new font.
