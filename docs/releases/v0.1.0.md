# Fork for Linux (unofficial) v0.1.0 — First public release

Fork for Linux (unofficial) runs the **official, unmodified** [Fork](https://git-fork.com) git
client for Windows under Wine. Fork is made by **Dan Pristupov and Tanya Pristupova**; this
project is **not affiliated with, endorsed by or supported by** them. Fork is paid software:
the evaluation is free, please [buy a license](https://git-fork.com/buy) if you keep using it.
Report wrapper problems at https://github.com/ventura8/Fork-Linux/issues, not to Fork support.

## Highlights

- **`fork-linux` CLI and `fork` command**: `fork ~/src/repo` opens a repository; the first run
  sets everything up lazily and resumably (a pinned Kron4ek Wine 11.0 staging WoW64 runtime,
  .NET Framework via winetricks, the official Fork installer from `cdn.fork.dev`, all
  verified by size + sha256 before use).
- **Desktop integration**: menu entry, AppStream metainfo, our own neutral icon (Fork's icon is
  extracted from your own `Fork.exe` at runtime), "Open in Fork" for Nautilus, Nemo, Caja,
  Dolphin, Thunar and FileManager-Actions, manual pages, bash / zsh / fish completions.
- **Safety**: a snapshot of Fork's install before every launch, `rollback`, version pinning,
  `doctor` with `--fix` and `--json`, `logs --bundle`, a reversible `uninstall` (`--purge`
  deletes only what fork-linux created; `~/.wine` is never touched).
- **Experimental native-git bridge** (`git-bridge enable`): Fork's git calls run the host's
  git through small MinGW shims and a loopback daemon; off by default.

## Install channels (amd64 / x86_64 only)

| Channel | Artifact |
|---|---|
| Installer script (per user, `~/.local`) | `install.sh` + `fork-linux-0.1.0-x86_64.tar.gz` + `SHA256SUMS` |
| Debian / Ubuntu | `fork-linux_0.1.0_amd64.deb`; PPA `ppa:ventura8/fork-linux` (22.04, 24.04, 26.04) |
| Fedora 44 | `fork-linux-0.1.0-1.fc44.x86_64.rpm` |
| openSUSE Leap 16.0 | `fork-linux-0.1.0-1.lp160.x86_64.rpm` |
| Arch Linux | `fork-linux-0.1.0-1-x86_64.pkg.tar.zst`; AUR `fork-linux` |
| AppImage | `fork-linux-0.1.0-x86_64.AppImage` (+ `.zsync`; uses the host Python >= 3.10) |
| Flatpak | `io.github.ventura8.ForkLinux-0.1.0-x86_64.flatpak` (org.winehq.Wine BaseApp, wow64-25.08) |
| Snap (classic) | `fork-linux_0.1.0_amd64.snap` |

No package depends on the distribution's `wine`, bundles Fork, or ships maintainer scripts:
all Wine state is created per user at first run.

## Known limitations

- "Show in Explorer" with a file selected opens the folder (Wine's explorer `/select`).
- Signing in to a GitHub account inside Fork can crash on Wine's WinRT notifications; use a
  personal access token instead.
- Wayland sessions use XWayland.
- Each new Wine prefix may use one of the license's 3 machine activations: deactivate your
  license in Fork before `fork-linux uninstall --purge`.
- The native-git bridge is experimental.
