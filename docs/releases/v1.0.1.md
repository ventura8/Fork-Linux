# Fork for Linux (unofficial) v1.0.1 — System file dialogs

Fork for Linux (unofficial) runs the **official, unmodified** [Fork](https://git-fork.com) git
client for Windows under Wine. Fork is made by **Dan Pristupov and Tanya Pristupova**; this
project is **not affiliated with, endorsed by or supported by** them. Fork is paid software:
the evaluation is free, please [buy a license](https://git-fork.com/buy) if you keep using it.
Report wrapper problems at https://github.com/ventura8/Fork-Linux/issues, not to Fork support.

## What's new

- **System file dialogs** (on by default): File → Open Repository, Clone, Save as Patch and
  other Common Item Dialogs open your Linux file picker (`zenity`, or `kdialog` on KDE / LXQt)
  instead of Wine's. Implemented as `fl-filedlg.dll` registered for `FileOpenDialog` /
  `FileSaveDialog`, calling `fl-launch.exe pick-dir|pick-file|save-file` through the launcher
  daemon to `fork-linux-host`. Turn off with
  `fork-linux config set integration.system_file_dialogs off` (then run setup / the next
  launch so the CLSID registrations are cleared).
- `doctor --check prefix.system_file_dialogs` reports whether the Linux pickers are wired.

## Install

Same channels as v1.0.0: GitHub Release packages and `ppa:ventura8/fork-linux`. After an
upgrade, the next `fork` / `fork-linux run` re-runs only the setup steps that changed
(`host_shims`, `host_integration`).
