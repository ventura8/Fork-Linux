**Fork for Linux (unofficial)** runs the official, unmodified [Fork](https://git-fork.com) git client for Windows under Wine, with a menu entry, a `fork` command, update snapshots with rollback and a health check.

### Install (amd64 / x86_64)

```sh
curl -fsSL https://github.com/ventura8/Fork-Linux/releases/latest/download/install.sh | bash
```

Or pick a package below: `.deb` (Ubuntu 22.04+ / Debian 13), `.rpm` (Fedora 44, openSUSE Leap 16.0), Arch `.pkg.tar.zst`, AppImage, Flatpak bundle, classic snap, or the relocatable tarball. Verify downloads with `SHA256SUMS`. The first run downloads a pinned Wine runtime, .NET Framework (under Microsoft's terms) and the official Fork installer from `cdn.fork.dev`, each verified by sha256. Nothing touches `~/.wine`.

### What's in v1.0.0

- Lazy, resumable setup; `fork <path>`; menu entry; "Open in Fork" in file managers
- Snapshots before every launch, `rollback`, version pinning
- `doctor` (`--fix`, `--json`), `logs --bundle`, reversible `uninstall` / `--purge`
- Experimental native-git bridge (off by default)
