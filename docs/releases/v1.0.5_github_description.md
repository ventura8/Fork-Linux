**Fork for Linux (unofficial)** runs the official, unmodified [Fork](https://git-fork.com) git client for Windows under Wine, with a menu entry, a `fork` command, update snapshots with rollback and a health check.

Report wrapper problems [here](https://github.com/ventura8/Fork-Linux/issues), not to Fork support.

### Install (amd64 / x86_64)

```sh
curl -fsSL https://github.com/ventura8/Fork-Linux/releases/latest/download/install.sh | bash
```

Or pick a package below: `.deb` (Ubuntu 22.04+ / Debian 13; also the PPA `ppa:ventura8/fork-linux`), `.rpm` (Fedora 44, openSUSE Leap 16.0), AppImage, Flatpak bundle, or the relocatable tarball. Verify downloads with `SHA256SUMS`.

### What's in v1.0.5

- **IDE icons in Open in**: each entry shows the Linux IDE's own icon (from its desktop entry: system, snap or Flatpak)
- **Crisp, evenly spaced text**: the interface font is now Noto Sans (installed as "FL UI Sans") instead of Selawik, whose hinting spaced letters unevenly under Wine; semibold and bold keep their weight
- E2E checks every Open in icon on screen and the new interface faces
