# Legal Guardrails

Fork EULA, branding, credits and no-redistribution rules.

Canonical rules: [AGENTS.md](../../../AGENTS.md).

- Never redistribute, patch or decompile Fork; download only from `cdn.fork.dev` on the user's machine (hard rules 1-3).
- "Fork for Linux (unofficial)" everywhere; the disclaimer, developers' names and https://git-fork.com/buy stay in the
  README, CREDITS, `about`, consent dialog, metainfo, `.desktop` comment, package descriptions and release notes.
- No Fork logo, icon or screenshots in the repo, packages or CI uploads; the E2E workflows upload logs only.
- Bug reports go to this repository; `support@fork.dev` only for licensing.
